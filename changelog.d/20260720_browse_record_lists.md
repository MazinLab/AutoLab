## Browse record lists (2026-07-20)

The catalog browser's entity-type dropdown is gone. The home page now mirrors
the New record page: themed Fab and Testing panels (plus "Everything else")
whose buttons open routable per-type list pages (`/browse/wafers`,
`/browse/fab-equipment`, ...). Each list shows type-specific columns (wafer
material and diameter, equipment kind and location, setup base temperature,
markdown body snippets for experiments and recipes), defaults to most recently
updated first, and keeps the sortable headers and text filter. Equipment lists
split instruments by category and note lists split by template (Experiments,
Fab Notes, Maintenance), with accession and name linking to the record page.
