## Litho red display theme (2026-07-21)

Third display theme for the lithography bay: red-only "80s arcade phosphor"
styling (square corners, mono display caps, red CRT scanlines and vignette,
phosphor glow). Photoresist safety is guaranteed by a full-screen pure-red
multiply overlay that zeroes the green and blue channels of everything
composited — including uploaded images and the lightbox — so on OLED panels
the blue subpixels are fully off. The header toggle is now a three-way
Default / Dark / Litho selector (the LCARS theme is labeled "Dark"). Litho
shares the dark skin's layout rules, so new components styled for Dark are
automatically styled for Litho.
