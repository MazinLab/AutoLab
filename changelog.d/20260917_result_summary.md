### Result summaries

- New Testing record **Result Summary**: a table of analyses bearing on one idea, across projects. Rows are analyses; columns are their named results.
- Analyses record **Results** as key / value rows (units in the key name, e.g. `base_temp_mk`), on the New form and on the record page. Clones carry them over.
- Add an analysis to a summary from the summary page (search) or from the Analysis form / record page. A summary's columns can be reordered, relabeled, or hidden; the table downloads as CSV.
- Project pages list the result summaries that include the project's analyses.
