# ben-force lessons — AutoLab

Verified rules distilled from past builds (one fact per entry; only facts confirmed during a build).

## 2026-07-18 — Plan 1 catalog foundation (PASS, 1 revision loop)

- SQLModel `Field(datetime)` renders a NAIVE `sa.DateTime()` column unless
  `sa_type=UTCDateTime` is passed explicitly — the mixin's shared type does not
  propagate to plain datetime fields. Verified: `Event.at` shipped naive in the
  autogenerated Alembic revision and was caught by round-0 inspection.
- `table=True` SQLModel classes skip pydantic validation on construction, so
  typed payload values (e.g. ISO date strings for datetime fields) reach the
  DB uncoerced unless the service layer validates explicitly. Verified:
  round-0 inspection; fixed in create_entity.
- Cross-table search must apply a deterministic ORDER BY inside each per-type
  query BEFORE its LIMIT; limiting unordered subqueries then globally sorting
  drops true matches. Verified: round-0 inspection of /api/search.
- Interpolating a raw DB password into a SQLAlchemy URL in compose breaks on
  URL-special characters (`a@b`); quote or use env-var indirection. Verified:
  round-0 inspection of docker-compose.yml.
- Bypass-permissions mode is the working path for codex-backed builds: all
  codex babysitters ran (codexReviewRan true, 41/41 agents, 0 errors) after
  auto-mode had killed them at spawn in the prior session.
- The plan doc's Task 1 pip line `pip install -e ".[dev]" .` is a typo
  (duplicate target, ResolutionImpossible); the correct form is
  `pip install -e ".[dev]"`.

## 2026-07-18 — Plan 2 artifacts/labdata ingestion (PASS, 1 revision loop)

- Contract-pinning rubric check scripts written BEFORE launch (fixing exact
  function signatures and result-dict keys) let five WPs land coherently with
  zero API-mismatch findings; the coders read the scripts first as directed.
- Catching broad `httpx.HTTPError` in a retry queue conflates permanent 4xx
  rejections with transient outages — entries retry forever with no signal.
  Verified: escalated design finding on the labdata spool; resolved by
  dead-lettering non-retryable statuses (retry only TransportError/5xx/429).
- The in-workflow Architect triage correctly escalated only the one genuine
  policy decision (spool error model) and the session answered it with one
  AskUserQuestion; no design findings were mechanically folded that needed
  human judgment.
- `git stash push` before the checkpoint reword replay, `stash pop` after,
  cleanly layers an in-session fix commit on top of the reworded history.

## 2026-07-18 — Plan 3 MCP server (PASS + manual adversarial review, 6 findings fixed)

- The workflow's codex review stage silently didn't run (codexReviewRan
  false) yet the verdict was PASS with zero findings — a clean grader pass
  is NOT evidence the adversarial review happened. Check codexReviewRan and
  run the review manually in-session when it is false; this run's manual
  review found 6 real bugs the inspector+grader missed.
- SQLite PRAGMA query_only does NOT make a connection side-effect-free:
  PRAGMA journal_mode and ATTACH DATABASE still succeed (verified: ATTACH
  created a file on disk). A read-only SQL surface needs a sqlite3
  authorizer allowlisting READ/SELECT/FUNCTION/RECURSIVE.
- np.float64 vs large-int comparisons coerce the int and can keep the
  rounded float on ties: track exact integer extrema separately from float
  accumulators.
- Coercing arrays to float64 for stats silently drops imaginary parts —
  MKID IQ data is complex; stats must branch on dtype.kind.
- Modeling: give the annotation TARGET a distinct relation (annotates) from
  evidence (refers_to) — identical edges lose which entity the annotation
  concerns.
- pipe codex review output through tee to a file, not just tail — findings
  scrolled out of the terminal capture this run.

## 2026-07-19 — Plan 5 labels/QR (PASS, 2 revision loops, zero review findings)

- The Zebra ZPL path needs no Python imaging deps: ^BQN generates the QR
  on-printer; keep raster (Brother/PIL) out until a Brother printer exists.
- Send-then-record is the right order for physical side effects: a printed
  label exists regardless of what the DB does afterward, so the event
  follows the send and a socket failure records nothing.
- ZPL text fields are an injection surface (^ and ~ are commands);
  neutralize control characters in any user-derived label text.

## 2026-07-19 — Plan 6 ops/backfill (PASS) + real-data validation

- Synthetic fixtures are necessary but not sufficient for import tooling:
  the real Leiden export contained a mutual reply cycle (75<->76) that no
  fixture anticipated and that aborted the whole import. Always run
  importers against the real dataset before declaring done.
- Backfill importers must degrade bad legacy metadata to warnings +
  summary counters, never abort: cut cycles at the entry recursing into
  its own ancestor (preserves parent-before-child creation order for
  everyone else), skip only the affected link.
- A coder babysitter legitimately fixed a bug in a rubric CHECK script
  (TemporaryDirectory closed before a later re-read) — harness bugs
  happen; the babysitter correctly identified it as harness-not-
  implementation and preserved every assertion. Review such fixes at the
  gate, don't assume check edits are gate-weakening.
